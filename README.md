# GRC Atlas — Obsidian Vault

Private, version-controlled relational discovery layer for the GRC Atlas and GRC Mapping research.

## System role

This repository is not the canonical system of record.

- **Notion / GRC Atlas** — canonical definitions, research decisions, provenance, promoted findings
- **Obsidian** — relational discovery, graph exploration, emergent pattern recognition
- **GitHub / this repo** — version control and bridge for the Obsidian Markdown vault
- **GRC Analysis Engine** — deterministic computation and reproducible analysis
- **GitLab / Multi-Framework Assurance** — protected calibration and validation
- **VR** — future immersive interface over governed research topology

## Canonicality rule

Obsidian may surface candidate relationships, hypotheses, clusters, and patterns. Those become authoritative only after validation and promotion back into the GRC Atlas.

## Core flow

`Atlas object → Obsidian representation → graph exploration → candidate finding → analysis / validation → Atlas finding`
